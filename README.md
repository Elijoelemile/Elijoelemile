### 🏭 AutoMeca — Plateforme de maintenance prédictive IoT (de la donnée au modèle en production)
> Plateforme complète pour un équipementier de freinage automobile, avec un objectif métier de **-30 % d'arrêts non planifiés**. Elle est découpée en 4 dépôts et **réellement déployée sur le cloud souverain européen Scaleway** :<br>
> 🏗️ **Architecture** : diagramme Edge/Cloud, MCD Merise, star schema PostgreSQL et télémétrie ClickHouse, sécurité IT/OT et RGPD<br>
> 🔄 **Pipeline ELT batch + temps réel** : MQTT → Kafka → ClickHouse (vue matérialisée RMS vibratoire), orchestration Airflow, quarantaine qualité, pseudonymisation, supervision et alertes Grafana, **60 tests** dont 8 sur une vraie infrastructure<br>
> 🤖 **Modèles IA** : détection d'anomalies (Isolation Forest, **AUC 0,93**) et durée de vie résiduelle (Random Survival Forest, **C-index 0,79**), explicabilité SHAP, suivi et registre MLflow<br>
> 🚢 **CI/CD & MLOps** : API FastAPI de tickets de maintenance avec validation humaine obligatoire, détection de dérive (PSI), interface Streamlit, GitHub Actions, **56 tests**
